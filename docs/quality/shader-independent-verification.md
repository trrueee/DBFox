The same cold Electron production path subsequently completed Run `run_82aac163b7624fa88fb1603f3fcbda6b` in 4,650 ms, with 9 native tool calls, all attempts 1, and 8 Artifacts. Actual driver diagnostics identify BROKEN_TOKEN on fragment line 4; one local source patch removes it, compile succeeds, preview produces actual pixels, and the exact v3 revision exports. `audit_native_agent.py` checks the public RunItems separately from the model script.
2. **A 319 CSS-pixel Dock used desktop-width media queries and overflowed to 610 pixels.** Native source/preview interactions clipped the workspace horizontally. Director changed the existing CSS to named container queries in 003eb7ec. Cold re-sign proof measures work area client/scroll both 311 pixels; native preview is reachable by normal vertical scrolling. Fullscreen remains 1,440 pixels with 1,110/330 columns. Before/after screenshots and measured bounds are retained.
3. **Cancellation after the real receipt INSERT could still commit an owner edit.** Independent injection at the existing receipt/transaction boundary produced a cancelled ToolResult while the created document and generation 1 remained durable. Director moved the existing cancellation checks after receipt writes immediately before transaction completion in ad83881d. Independent create and negative compile-report fences now both pass (2 tests / 7.11 s). The report branch uses an explicitly unsuccessful compute response solely to test transactional rollback; it is not GPU success evidence.
4. **Canonical document Artifacts were rejected because their optional `report_id` is null.** All four actual revision cards in the native Agent Run displayed a parse error, while compile/preview cards worked. An independent fixture using all eight actual public producer payloads reproduced the failure. Director corrected the existing parser in efb9167f without transforming the schema. A fresh signed cold launch opened immutable v1 source and downloaded its JSON, then repeated the download after native deletion advanced current head to v4. Clicking the historical failed v2 diagnostic opened read-only BROKEN_TOKEN source on line 4, with Save disabled. Independent JSON/page/source/hash audits passed.

## Verification fixture corrections retained

The initial CLI script used an unavailable sandbox `URL` global; it failed before writes and was corrected to parse the known API boundary. Another initial script completed its writes/actions before incorrectly waiting for a CSP meta tag; read-only public audit recovered those outcomes without replay. CSP is a response header in the production renderer proof.

The first Agent driver used `ConversationSnapshot.id` rather than the public `session.id`, creating only an empty conversation before admission failed. It was corrected and only that verified empty conversation was reused. The minimal factory test's postconditions were corrected to the public observation status `succeeded` and HeadResult's actual four fields; the missing-resolver assertion and real factory boundary were not weakened.

Native CodeMirror insertion consumes the existing terminal newline. Its first postcondition expected an extra newline and failed after the already committed edit. Both public immutable sources were inspected, the exact expected text was corrected, and the write was not replayed. The first PNG oracle assumed normalized 0.5 always rounds to 128; inspection showed 127 is also allowed by the [Khronos OpenGL ES 3.0 specification](https://registry.khronos.org/OpenGL/specs/es/3.0/es_spec_3.0.withchanges.pdf). The corrected oracle still requires exact full-image bytes, orientation and matching hashes.

The report fence fixture initially assumed the first `compute.next` could not return idle, so it failed before its injection point. It now polls the real documented lease boundary within a finite deadline. This initial failure is not reported as a second independently reproduced cancellation defect.

The large workload model initially requested another edit after production RunLimits removed tools for finalization. Three controlled SSE assertions failed; the Run stopped with 59 stages and no GPU success claim. The explicitly continued Run performs only the remaining batch. The maximum-uniform fixture initially sent 129 operations against the documented 64-operation input limit (422 before writes), then incorrectly expected 422 for the separate 129th-uniform domain constraint (actual 400 after the valid v24 commit). Recovery first inspects v24 and verifies source/count before skipping those writes. An initial source-page limit of 200 was corrected to the documented 50; this was a read-only fixture error.

The first cancellation driver used the wrong URL and mishandled its held route during cleanup. That original Run instead reached the real compute deadline, then failed because the fixture had revoked its model credential. Its separate evidence is retained as `electron-cancel-first-fixture-error.json`; it is not counted as a successful cancellation scenario. The corrected new Run uses `/runs/{runId}/cancel`, waits for the held response to finish, and passed. A pre-admission attempt required explicit GPU reconnect after the prior failed handoff; no tool write was replayed.

Recovery tests initially assumed another DLC's stronger missing-receipt classification and failed three before-commit postconditions. The Shader accepted design explicitly returns unknown when no receipt exists. Only the public error expectation was corrected to `TOOL_OUTCOME_UNKNOWN`; the actual termination, old head, exact committed result, attempt count and no-replay checks remain.

Snapshot audit corrections fixed a test-side singular/plural count key and removed an assumed public `png_hash` field that does not exist. Actual PNG bytes are compared with the public immutable stream instead. Repeated export cards required selecting the last actual export card; no owner mutation was repeated.

The scope driver first read only visible `innerText`, omitting the narrow composer's hidden kind label, then looked for a newly API-created Session absent from the current cached navigation list. It now checks the actual reference DOM text and uses an existing visible Session. Project toggles also required waiting for their actual tree state. These failed driver attempts made no owner edits; the final response hold/release completed without route errors.
