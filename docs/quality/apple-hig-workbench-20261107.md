# Apple HIG 工作台设计与验收

> 文档类型：界面设计与实施证据
>
> 状态：当前
>
> 最后核验：2026-11-08
>
> 范围：Desktop Core UI、Host UI 与 13 个内置 DLC 的界面控件

用户要求全面采用苹果风格，并明确要求按每个功能的任务与交互进行设计。当前设计基础是 Apple Human Interface Guidelines；此前 Fluent 阶段的外观决策由本文替代。运行状态、权限、DLC 所有权和耐久数据合同继续保持唯一事实源。

## 采用依据与边界

调查了现有 Radix、shadcn、Prompt Kit、Agent Elements、Zag 和 TanStack 的生产实现，以及 Apple 官方的
[材质](https://developer.apple.com/design/human-interface-guidelines/materials)、
[界面图标](https://developer.apple.com/design/human-interface-guidelines/icons)、
[侧栏](https://developer.apple.com/design/human-interface-guidelines/sidebars)、
[工具栏](https://developer.apple.com/design/human-interface-guidelines/toolbars)、
[设置](https://developer.apple.com/design/human-interface-guidelines/settings)和
[动效](https://developer.apple.com/design/human-interface-guidelines/motion)规范。

采用现有成熟交互原语，调整任务路径、默认信息、展开层级、材质与反馈。没有引入新的主题、布局、动画或图标运行时。
Electron/CSS 实现 HIG 启发的功能层与内容层；不声称 Windows 客户端使用了原生 Liquid Glass API。
窗口控制与快捷键保留所在平台的行为。当前真实验证平台为 Windows x64，未声称完成 macOS 发布验收。

图标使用既有 MIT 许可 Phosphor 原始 SVG，在权威生成清单中将 34 个双色默认项改为 regular。
Core 直接调用与 DLC 经 Host 调用都使用一致的单色语法；播放、暂停和必要状态可使用实心形状。
文件和品牌仍使用真实标志。未把 Apple 的系统符号或字体打包到 Windows：相关限制见
[Apple 系统图像许可](https://www.apple.com/legal/sla/docs/xcode.pdf)及[字体许可](https://developer.apple.com/fonts/)。
现有素材的固定版本、SHA-256 和许可证保持不变。

## 逐功能设计与实施

| 功能 | 用户任务与当前设计 |
| --- | --- |
| 项目与对话导航 | 文件夹项目是工作上下文，对话是可进入的任务。单色图标、中性整行选中、当前文件夹位置语义；不恢复资源分类树或最近工作面板。 |
| 新任务与输入 | 一处标题、一处输入；标准加号、圆形发送、单行文件引用。只保留会影响下一条消息的模型和发送方式，不增加宣传式占位文字。 |
| 线程状态 | 保留耐久 cursor/快照/SSE 投影；状态信标、待介入排序和审批入口保持真实，不用动画或发送状态推断完成。 |
| 工具记录 | 默认折叠，按需挂载参数与结果；保留用户手动展开，不随运行结束收回。 |
| 等待审批 | 当前风险、目标和明确批准/拒绝保持可见；不为简约隐藏安全决策。已批准/拒绝的历史折叠为状态与操作名，展开才挂载详细内容。过期、取消和失败说明继续可见。 |
| 补充问题 | 直接呈现业务问题与真实圆形单选，移除 1/1、题号和 A/B 装饰；继续复用 Radix 的单选与键盘语义，不自动替用户回答。 |
| 输入连续性 | 新审批或问题只在 body 持有焦点时尝试聚焦，不抢走正在编辑的草稿。组件选择与服务器等待状态分开。 |
| 文件与引用 | 文件夹树、代码和 Markdown 渲染各用适合内容的视图；引用按规范 Artifact 的类型显示图标，点击进入同一 Dock 身份。加入上下文后以真实引用状态显示勾选，避免常规成功 Toast 遮挡输入。 |
| Dock | 浮动工具栏构成功能层，文件与专业内容保持稳定底色。沿用现有开合与标签状态、宽度规划和溢出菜单；紧凑返回保持编辑器、草稿和焦点，不复制一套抽屉状态。 |
| 外观设置 | 主题、密度、字号放在默认路径；颜色、分区字体、行高与辅助功能进入既有高级展开区。相关偏好组成内容分组，预览使用真实组件并保持 inert。 |
| 模型连接 | 首先选择服务商、密钥和模型。已知服务地址按需展开；自定义或无效地址自动暴露可编辑字段。模型列表刷新使用相邻图标；保存与测试结果仍由真实请求决定。 |
| 项目配置 | 删除“由扩展提供”等重复说明，以及空资源的重复占位；保留已配置数量、具体配置动作和错误恢复。项目设置视图按项目 ID 挂载，旧项目异步结果不进入新项目界面。 |
| 扩展管理 | 保留开关、当前激活和待重启的区别；版本、指纹与技术详情按需展开。集合沿用自身列表表面，避免在偏好分组内再嵌套多层卡片。 |
| 启动与失败 | 首帧遵循系统浅/深色，使用品牌标志与独立小型等待指示；减少动效停止旋转。启动与恢复由真实 Engine 状态驱动，保留重试和诊断路径。 |

## 内置 DLC 的设计边界

13 个内置 DLC 的控件在各自 owner 源码中接入共享圆角、尺寸、颜色和过渡，没有通过 Host 全局覆盖第三方 Renderer。

| DLC | 内容与操作的取舍 |
| --- | --- |
| Workspace | 目录层级与文件读取保持 Zag/Owner 合同；代码、Markdown 和引用各有清楚入口。 |
| Data | 连接、目录、表结构与样例保持独立任务；结构/数据采用分段选择。目录刷新仍是明确操作，保留资源版本和不可变目录事实。 |
| Story | 默认呈现目录、关系图与待审内容；添加实体/关系使用原生 disclosure 按需展开，收起保留草稿。目录“新增”打开对应表单并聚焦名称。逻辑/章节采用明确的分段选择与 pressed 语义，刷新为相邻命名图标。章节与修订继续走原领域流程，内容不使用导航玻璃。 |
| Music | 播放/暂停保持标准实心符号，录音/谱面/钢琴内容保留专业语义；不对高频演奏交互添加延迟动画。 |
| Comic | 页面、镜头和对象保留领域层级；按钮和表单统一材质与反馈，画面不被控件效果覆盖。 |
| Pixel | 像素画布、图层和色板保留内容颜色；外围工具与属性控件采用一致比例。 |
| Animation | 时间线、轨道和帧操作保持直接响应，外围表单使用同一套尺寸和圆角。 |
| Scene | 场景与属性分层，专业画面和导航控制分离；保留既有容器宽度适配。 |
| Voxel | 画笔、色板和属性操作使用统一控件，三维内容不重着色为应用外壳。 |
| Shader | Pass、Uniform、代码与预览保留专业层级，外围控制采用共享角色，不叠加玻璃到代码区。 |
| Game | 模式选择使用分段控件，运行内容与编辑控制分离，保留执行器真实状态。 |
| Visualization | 图形编码继续由现有 Vega/Vega-Lite 与数据合同负责；Toolbar、错误和数据替代视图遵循 Host 规范。 |
| GitHub | 仓库连接、文件与成果继续使用原权限与资源合同，表单和工具栏统一；不自动发起账号连接或写入。 |

## 共享比例与材质

- 界面 15px、对话 16px、数据/代码 14px、首页标题 32px；沿用合法的用户偏好。Apple 系统字体在 macOS 上优先，其他平台使用本机字体，不加载网络字体。
- 行圆角 10px、按钮/输入 12px、内容组 16px、面板/对话框 20px、Composer 24px；发送保留 40px 圆形操作，常规图标 20px，紧凑符号 16/18px。
- 中性选中强调位置与字重，不叠加蓝色竖边；分段选择通过轻微抬升表达当前项。蓝色用于明确动作、焦点与链接，状态色保留业务意义。
- 导航/工具栏与浮层使用独立材质；普通内容、表格和决策文本保持稳定底色。减少透明度、增强对比度与强制颜色使用实色或系统轮廓。
- 140/200/260ms 的短反馈、进入与退出；不动画化流式文本、分栏宽度和高频专业输入，不引入持续装饰性动画。

## 实机发现的结果合同缺口

真实 SQLite 表结构可以读取，但数据样例返回缺少持久结果的错误。调查发现 `data_preview` 生产的是带 `sample_rows` 证据语义的 `dbfox.data.snapshot`，而 `table.preview` 消费端错误地寻找普通查询的 `dbfox.data.result_view`。
已在消费端选择生产者的规范 Snapshot，继续保持样例语义与来源 SQL 关系；不更改 SQL 执行链、不增加类型兼容表、不把样例伪装成完整查询结果。
回归扩展已有生产包、真实 SQLite 与 Action Run 测试，分别检查 Console 与样例的实际 Artifact 类型、持久来源关系和 Run 终态。
修复前同一回归中 Console 通过、预览复现错误；修复后相关两个模块 24 项通过。重启隔离客户端后，通过正常界面点击“数据样例”，实际显示 SQLite 的三行内容，无页面横向溢出。

## 验证记录

- 完整前端串行回归：117 个文件、739 项通过，包含输入焦点保护与真实 DLC 源码 fixture。
- 最后增加的 Story disclosure 调整另跑现有 Story 与 DLC 视觉合同：2 个文件、6 项通过；真实界面补验默认收起、分支新增聚焦、收起保留草稿、关系表单展开与章节阅读。6 项是已有回归的重跑，不与 739 相加。
- `npm run lint`、`npm run typecheck:test`、`npm run build` 通过。Lint 保留 25 条现有 Fast Refresh 警告、0 错误；DLC 设计令牌合同未放宽。
- 生产入口为 647,642 B，预算脚本计算 gzip 195,720 B；生产 Token 与打包协议检查通过。未为材质或动效增加运行时依赖。
- 后端相关回归 24 项通过；两个改动 Python 文件通过 Pyflakes。没有重新运行整套后端系统测试或 Frozen Sidecar 发布验收。
- 图标来源与生成合同继续检查 100 个图形、300 个原生 SVG 状态，以及 20 个本地品牌标志。
- 实际界面使用隔离 QA runtime；7 个已安装扩展均正常激活。未修改用户安装版或其凭据。
- 文件预览/源码切换、加入引用后勾选、移除引用后恢复入口、无常规成功 Toast 均通过实际操作。720px 窗口返回对话后草稿和焦点保留，输入区实测约 331px，无页面横向溢出。
